# Changelog

## 0.1.0 (2026-11-16)

- Harness with seven rules: ledger, final status, ordering, rollback, authentication, replay and liveness.
- Instant, ACH and on-chain lifecycle models; Standard Webhooks signing; retries on the spec's example schedule.
- Shrinking to the smallest failing case, saved as JSON and replayable.
- Naive, short-dedupe and careful reference receivers, and an example built from webhook-verify and idempotency-store.
